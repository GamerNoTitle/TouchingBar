# 布局与网络组件演示

`layout-network-demo.json` 是独立的备份配置，不是新增内置预设，程序不会自动加载它。

演示包含时间、Wi-Fi 名称、本机 IP、VPN / 隧道状态、延迟、上传与下载速度。总宽度超过一个 Touch Bar 可视范围，用于测试横向滚动、拖动排序、点击选中和拖动边缘调宽。

## 安全试用

1. 在设置 → 备份与恢复，先导出你当前的备份。
2. 注意：“从备份文件恢复”会**替换整个当前配置**，不是合并组件。确认已备份后再恢复本演示文件。
3. 在 Touch Bar 配置页面选择演示配置查看布局预览；点击组件会选中相应编辑器。拖动组件排序，拖动选中组件右侧蓝色边缘调整宽度（松手后应用到实体 Touch Bar）。
4. 本机 IP 组件在实体 Touch Bar 上点击即可复制。VPN 是活动隧道接口的启发式状态，不保证是某个 VPN 软件的真实连接状态。
5. 延迟组件默认**没有目标、不发送探测请求**。选中它并填写你自己的主机名或 IPv4 地址后，在此配置实际显示时每 10 秒低频探测（最多 4 个不同目标）。超时仅表示目标未响应 ICMP，不代表整机断网。
6. macOS 可能限制 Wi-Fi 名称读取，名称不可得时显示提示，不会显示虚假 SSID。
7. 试用后恢复第 1 步导出的个人配置。

预览中网络、歌词等为明确标注的示例文本，不是实时数据；隐藏组件不占宽度，条件隐藏的组件仍显示以便编辑。操作按钮/媒体内容类型使用固定宽度，只有组件式布局支持拖边调宽。
